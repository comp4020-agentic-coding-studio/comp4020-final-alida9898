# 头脑风暴记录

2026-10-05，和 Claude Code 的第一次头脑风暴。记录想法怎么一步步变过来的，
以后写 PROCESS.md 时可以引用。

## 想法的演变

1. 起点：地图类（喜欢 chartogne-taillet.com 那种手绘、纸感、可拖拽缩放的地图）
   + 拼贴、可以送贴纸。喜欢的是**视觉风格**和**交互手感**，不是地块结构。
2. 共享大地图 → 否决：所有人抢着贴，showcase 时会糊成一团。
3. 改成每人一本手账 → 景观贴纸（素材统一、好看）。
4. 质疑：一个人也能完成，多人很牵强。
5. "贴纸只能来自别人" → 否决，太狠；改为**自己有基础贴纸，别人送的更特别**。
6. 原型其实是**造景贴纸**：画面预先设计好，像乐高说明书一样按步骤一层层叠。
7. 担心想太远（推广、商业化）→ 决定：作业版只做核心体验，其余写进
   README 的"没做的"。
8. 核心感受定为**陪伴感：相互孤立又相互对应**。

## 当前设计

两个人各自拼一幅造景贴纸，两幅画是一对；拼起来溪水相连，小人隔着画框对话。

- **拼**：按步骤揭贴纸、对位、按下，一层层叠出景深。
- **一对**：每幅都是一对的一半，单独看完整、不突兀。
- **配对**：随机配陌生人 + 发链接邀请朋友（本质都是一个"房间"）。
- **连接**：两人都在时画在边缘接上，溪流流过去，触发**预设对话剧本**。
- **动作**：小人有一组**固定动作**（如挥手、放纸船）。
- 多人：两人各拼一半，app 分清是谁。
- 实时：对方贴一步 / 做一个动作，约 1 秒内出现在你这边。
- 持久：拼图进度、配对关系、剧本进度、**留下的痕迹**（如停在溪边的纸船）。
- 范围：作业版只做**一对场景，每边 8–12 步**。

## 第二轮（grilling，同日）定下的

- 素材方向换成"治愈咖啡店"三折页风格；两半 = 左：店门口和柜台，右：里屋座位，中间一扇门。
- 一个人也完整：自己拼完就是完整的一幅；两人同时在线时门打开，猫店员端咖啡穿过去（代替溪水）。
- 异步为主，同时在线才连接；每一半一条秘密链接即身份；随机配对 = 先填别人空着的半边房间。
- 拖到附近松手吸附；对话随双方进度解锁；动作 = 挥手 + 送咖啡（咖啡留在对方桌上 = 痕迹）。
- 对方拖动时能看到半透明猫爪（"小幽灵手"）→ 实时用 WebSocket（第 10 周）。
- 存储 SQLite（`/data`），Node + TypeScript。
- 图片用课程额度生成（recraft-v3，招牌用 ideogram）；每张贴纸单独白底生成再抠图；背景只生成纯纹理，用代码拼，避免模型自己画家具破坏层次。prompt 全部记录在 `assets/generations.jsonl`。
- **步骤顺序 ≠ 遮挡顺序**：清单里每张贴纸有 `step`（第几步贴）和 `z`（前后层级），例如猫店员第 7 步贴，但站在吧台（第 6 步）后面。
- 暂缓：素材排版器、CLAUDE.md。

## 第三轮（2026-10-06 凌晨）：转向"小镇"+ 自由摆放

起因：自己拼了第一版，觉得前后关系不对、看不到两个人的互动。

- **大方向**：整个小镇是一张地图，大家一起把它填满，从咖啡店开始；点进一块地，选自己想拼的部分。
- **两个人的关系 = 邻居**：一个人认领一块地，隔壁就是"另一半"（咖啡店 ↔ 花店），可以挥手、送东西、开门。
  每块只有一个主人，所以不会出现之前否决的"共享地图糊成一团"。
- **作业版范围**：咖啡店 + 一家邻居店（花店，约 8 张贴纸），其余地块显示"待建"。
- **店外放在地图上**：遮阳棚、立式招牌是店面，放到小镇地图上；点进去的两块都是店内（柜台区 / 座位区），用同一套墙纸。
- **背景板固定**，不再是第 1 步。
- **自由摆放**：贴纸可以放在任何位置，不按顺序；推荐位置显示淡淡的轮廓，靠近时轻轻吸附；贴好的能拿起来重摆，拖回托盘 = 撕下来。托盘格子固定，拿走留空位。

### 图层规则（自由摆放的核心，已在原型实现）

| 类型 | 例子 | 放置 | 遮挡 |
|---|---|---|---|
| 挂墙 wall | 招牌、窗、钟、藤蔓 | 只能在地板线以上，放低会被推回墙上 | 在所有落地的东西后面 |
| 铺地 flat | 地毯 | 地板上 | 在所有站着的东西下面 |
| 落地 floor | 柜台、书架、椅子、盆栽 | 脚必须落在地板上，否则自动往下落 | 脚越靠下越靠前 |
| 台面 surface | 咖啡机 | 自动落到最近的家具台面上；没有家具就弹回托盘；家具移动时跟着走 | 紧贴在那件家具前面 |
| 坐 sit | 猫客人 | 丢到椅子上就坐进去 | 紧贴在椅子前面 |

### 对贴纸本身的要求（这次出问题的根源）

1. 一张贴纸只画一件东西，不能自带别的物件。
2. 正面视角。
3. 能当台面的家具，台面必须是空的（清单里用 `top` 标出台面高度；吧台自带的杂物用 `cropProps` 自动裁掉）。

### 流程约定

改图层之前先出设计（表 + 示意），确认后再生成或修改图片。

## 第四轮（2026-10-06 下午）：核心玩法要解压，不要"动脑子"

起因：担心第三轮的"自由摆放"削弱了最初想要的解压感——造景贴纸的核心本来是
"照着贴、不用想"，自由选位置变成了要思考"放哪儿"。

- 诊断：第三轮其实解决了两个不同的问题——(1) 遮挡顺序算错了（技术问题，该让
  图层规则自动处理，跟用户要不要想无关）、(2) 两人互动看不见。"自由摆放"是顺手
  加进来的，真正该拆掉的是它，不是图层规则。
- **决定（方向 A）**：贴纸恢复**唯一预设位置**（像乐高说明书，照着贴、对齐、
  按下，不用选放哪），但前后遮挡仍由图层规则自动算（不再按"第几步贴的"定前后），
  这样顺序贴乱了视觉也不会错。"小镇/邻居"设定保留，但只是叙事上的理由，不再是
  "自由摆放"的理由。
- 对"方向 A 会不会因为内容量太小而玩完就没意思"的顾虑：判断这是假问题——这是
  门课的作业，不是要做可以无限重复玩的游戏，"一对场景、每边 8–12 步 + 美术做
  扎实 + 互动清楚可见"本身就是一次完整体验，不需要靠堆内容撑深度。
- 还没拍板：这个决定还没真人测试验证，之后要**找人实际玩一遍收集反馈**，再确认
  解压感是否真的回来了。
- 候补想法（先记录，不做）：放好咖啡机之后，能不能点一下自己"做咖啡"（小动画/
  音效）。按下不表的原因：这类主动交互正好是方向 A 刚想拿掉的"要做点什么"的
  负担，跟"不用动脑子"的核心有点矛盾；等拿到真人试玩反馈、确认"解压感"到底
  缺不缺，再决定要不要加。
- 顺手改了 `l-machine`（咖啡机）的生成 prompt：原来只写 "front view" 不够，
  recraft-v3 会自己加 3/4 透视角度；改成"symmetrical front elevation... viewed
  exactly head-on so the left and right sides are not visible, like a flat 2D
  icon with no depth"才稳定出正面。以后生成"落地家具/电器"类贴纸可以直接套
  这个措辞模板（`l-display` 当时也是试了 3 次才用类似措辞收敛，但仍留了一点点
  斜角瑕疵，见上面"已知瑕疵"）。
